# User Guide

## Try the product

1. Open [iuran-022.vercel.app](https://iuran-022.vercel.app).
2. Review the merchant dashboard and active membership plan.
3. Switch to the subscriber view.
4. Connect Freighter when a Mainnet action is offered.
5. Check that Freighter displays the expected account and network.
6. Review the contract call and fee, then sign.
7. Keep the transaction hash as your receipt.

## What success looks like

A successful action has a Mainnet transaction hash that can be opened in Stellar Expert. The explorer should show a successful invocation of the Iuran contract.

## Wallet safety

Never paste a secret key into the application or a support message. Decline any signature request whose network, contract, or method does not match the action you selected.
