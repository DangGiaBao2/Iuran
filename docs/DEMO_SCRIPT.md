# Demonstration Script

## Two-minute walkthrough

1. Open the live Iuran application.
2. Show the merchant view and explain the recurring plan.
3. Switch to the subscriber view.
4. Open the deployment manifest and show the Mainnet Contract ID.
5. Open the `create_plan` transaction in Stellar Expert.
6. Open the `subscribe` transaction.
7. Finish with the successful `charge` transaction.

## Talking points

- Users keep wallet custody.
- Contract authorization controls state changes.
- Unique charge identifiers reduce duplicate billing risk.
- Every demonstrated Mainnet action has an explorer-verifiable hash.

Do not claim that demo-mode UI records are live settlement unless the displayed action is backed by a confirmed Mainnet transaction.
