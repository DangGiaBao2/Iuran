# Release Checklist

## Code

- [ ] Application build passes.
- [ ] Contract tests pass.
- [ ] WASM builds with the pinned Soroban SDK.
- [ ] Deployment manifest is valid JSON.

## Configuration

- [ ] Production URL is public.
- [ ] Network is Mainnet.
- [ ] Contract ID matches the deployed instance.
- [ ] No secret key is bundled.

## Evidence

- [ ] Upload and deploy hashes are recorded.
- [ ] At least one complete functional flow is recorded.
- [ ] Explorer links open on the Public network.
- [ ] README reflects the current deployment.

## Handoff

- [ ] User guide is available.
- [ ] Troubleshooting and operations runbooks are linked.
- [ ] Known limitations are stated.
